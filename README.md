# 提示词方块（Prompt Blocks）

本地、离线、中英双语的提示词拼装工具：**基础句 + 点选修饰卡 → 槽位拼装 → 一键复制**。

给 AI 的提示词不再整包手改：点几张「手法型」卡片，拼成一条精准、可操作的指令，复制去喂给任何 AI。

## 启动

- 首次：`npm install`
- 日常开发：`npm run dev`，浏览器打开 http://localhost:5173
- 打包成单文件：`npm run build` → 产物 `dist/index.html` 可直接双击打开（离线可用）
- 跑测试：`npm run test`

## 怎么用（三步）

1. 在中间「拼装区」输入基础句（例：帮我审计这段代码）
2. 在左侧点卡片插入：**前缀卡**落到句子前段，**后缀卡**接句尾，**段落卡**附在最后；悬停卡片可看全文
3. 右下角「复制」，粘贴给任意 AI
4. 顶栏右上角切换界面语言（中文 / English）：首次打开按浏览器语言自动识别，选择会保存在本地；切换后 **UI、卡片内容、拼装与复制结果全部跟随语言**（英文版为内置英译层；术语本来就保留英文原名）

拼装区里每张已插入的卡都可以：停用（⏸）/ 上移（↑）/ 下移（↓）/ 移除（×）；带变量的卡可以就地填值（如「控制篇幅」的篇幅）。
预览栏支持「手动微调」：改过之后不再自动同步，点「⟳ 与拼装同步」可回到自动模式。

## 数据存在哪

- 浏览器 `localStorage`，键名 `prompt-blocks:v1`（当前存拼装区状态；用户卡与配方为 Step 2）
- 界面语言偏好单独存 `prompt-blocks:lang`（`zh` / `en`），与数据互不影响
- 换浏览器 / 清缓存会丢；Step 2 提供 JSON 导入导出做备份

## 怎么加卡（改代码）

1. 打开 `src/data/preset/` 下的分类文件（如 `secAudit.ts`），按文件头注释的格式追加卡片对象
2. 规则速记：id 用 `builtin:<分类>-<两位序号>`；`title` ≤ 24 字；`text` ≤ 160 字单行（多要点用「；」）；正文里的 `{变量}` 必须登记进 `vars`（变量名以中文或字母开头，`{{7*7}}` 一类载荷不会被误判）；`tags` 2-4 个
3. 到 `src/data/preset/en/` 对应文件补同 id 的英译（`title` / `text` / `tags`；带变量的卡在 `vars` 里给「原变量名 → 英文变量名 + 默认值」映射，正文变量写成英文 token，如 `{language}`）
4. 运行 `npm run test`：中文卡与英译层的唯一性 / 字段 / 变量登记会自动校验（缺英译、字段超长、token 没登记都会失败）

提示：卡片要写「手法型」指令——动作 + 对象 + 判定标准（怎么算命中、怎么排除假阴性），真实载荷/字段/工具名优先，能量化就量化，标准术语保留英文原名（BOLA、TOCTOU、gadget chain 等）。写法标准与调研依据见 `docs/research/2026-10-19-security-prompt-research.md`，术语来源见 `docs/research/2026-10-19-terminology-sources.md`。

## 目录结构

- `src/lib/`：纯函数核心（`compose` 拼装规则、`reducer` 状态、`storage` 存储、`cardUtils` 工具），全部有单测
- `src/data/preset/`：预置卡库（150 张，5 类：安全审计 / 渗透测试 / 编程 / 输出格式 / 通用）
- `src/data/preset/en/`：内置英译层（键为卡片 id；`localizeCard` 在 en 界面合并，变量用 `key` 指回原名保证已填值不丢）
- `src/components/`：三栏 UI（卡库 / 拼装区 / 预览）
- `docs/superpowers/`：设计文档与实现计划
- `docs/research/`：卡片写法与术语来源调研笔记（GitHub 网安 prompt / 概念库借鉴）

## 注意事项

- 断网可用，运行时不发任何外部请求；前端零后端，数据只存在你的浏览器里
- 拼接规则：槽内各段用「，」连接（英文界面用「, 」）；基础句以终结标点结尾时后缀直接连接；段落间空行分隔
